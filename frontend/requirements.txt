# =============================================================================
# Design Collision / frontend - Environment Notes
# This file is documentation, not a pip/conda lock file.
# =============================================================================
#
# [Node.js]
#   - Node.js 18+ and npm are required.
#   - Run from this directory:
#       npm install
#       npm run start
#
# [Python / Conda for STEP -> voxel conversion]
#   - The server runs the converter with:
#       conda run -n dc python tools/step_to_voxel.py ...
#   - If your conda environment name is not `dc`, update `server.js`.
#   - Required Python packages (recommended via conda-forge):
#       numpy, trimesh, open3d, pythonocc-core
#
# [Data root]
#   - Fixed path: <this directory>/data
#   - Required runtime files are read/written under this data root:
#       step/, voxel/, <STEP>.json, <STEP>_assembly.msgpack (optional)
#
# [Generated outputs]
#   - Uploaded STEP file:  <DATA_ROOT>/step/
#   - Voxel outputs:       <DATA_ROOT>/voxel/<stem>_voxel/
#                          (e.g. <stem>_case_1.npy, <stem>_1.npy, meta.npz)
#   - Manifest JSON:       <DATA_ROOT>/<stem>.json
#   - Assembly msgpack:    <DATA_ROOT>/<stem>_assembly.msgpack (optional; see README)
#
# =============================================================================
